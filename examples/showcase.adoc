== Admonitions

NOTE: A single-sentence note, written as a paragraph.

[WARNING]
====
A warning that spans several sentences.
Each sentence sits on its own line in the source.
Confluence renders this as a warning macro.
====

[TIP]
====
Tips and notes use different Confluence macros.
Whether that mapping is the one you want is worth checking here.
====

IMPORTANT: Important and caution map to their own macros as well.

CAUTION: This is the fifth and last admonition kind.

    public String toString() {
        return groupId + ":" + artifactId + ":" + version;
    }
